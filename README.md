# Flask Portfolio

A personal portfolio web application built using Python and Flask.

## Features

- Personal portfolio page
- Displays education and professional information
- Login functionality
- Comment functionality
- SQLite database for storing comments

## Technologies Used

- Python
- Flask
- HTML
- CSS
- SQLite
- Git and GitHub

## Project Structure

- `flask_app.py` - Main Flask application
- `templates/` - HTML templates
- `static/` - Images and other static files
- `comments.db` - SQLite database (excluded from GitHub)
